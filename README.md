# Block Launcher

A small Android launcher (Kotlin + Jetpack Compose). It lets you pick a game,
set a nickname, and press PLAY to open a game you already installed
(Minecraft Bedrock or PojavLauncher). If the game is missing, it opens the download page.

It does NOT include or download any Minecraft files. You must own the game.

## Build the APK online with GitHub (no computer needed)

1. Create a free account on github.com
2. Create a new repository (any name)
3. Upload ALL files from this project (keep the folders, including the hidden `.github` folder)
4. Open the **Actions** tab -> **Build APK** -> wait ~5 minutes
5. Open the finished run -> download **BlockLauncher-debug-apk**
6. Unzip it, open `app-debug.apk` on your phone, allow "install unknown apps"

## Build with Android Studio (if you get a computer)

Open this folder in Android Studio and press Run.
